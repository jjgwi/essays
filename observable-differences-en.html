Which differences are observable?

What a realized interface preserves, suppresses, or leaves undetermined about a global quantum state

The global state is not an internal data set

Quantum cosmology assigns a state, wavefunctional, or related object to the universe as a whole. Such a state can contain amplitudes, phases, correlations, and weights for different semiclassical histories. An observer inside the universe does not receive this global object directly. Empirical information arrives through physical records and observables supported by a realized interface.

Let $\mathcal A$ be a global algebra and $\mathcal A_I\subseteq\mathcal A$ the algebra available at an interface $I$. A global state $\omega$ supplies the interface state simply by restriction:

$$\omega_I=\omega|_{\mathcal A_I}.$$

This innocent-looking map is generally many-to-one. Distinct global states can agree on every observable in $\mathcal A_I$. The set of all compatible global extensions is the extension fiber:

$$ \operatorname{Ext}_I(\omega_I)= \left\{\widetilde\omega:\widetilde\omega|_{\mathcal A_I}=\omega_I\right\}. $$

This extension fiber is conceptually different from the split-realization fiber in the previous essay: there the freedom concerned possible interface realizations; here it concerns possible global states. Two states in the same extension fiber are indistinguishable at that interface. They need not be the same physical state, and the framework does not declare their difference unreal. They may differ in correlations, phases, environmental configurations, or relational structure outside the realized algebra. The correct conclusion is only that the present interface does not resolve the difference.

The interface algebra should be physically selected

An arbitrary list of quantities that an analyst chooses to inspect is not yet a physical interface. In the semiclassical setting of document 60, the algebra is selected by response: which physically allowed perturbations continue to produce stable, reproducible changes in observable variables?

One may represent the linearized response by a map from physical perturbation directions to variations of candidate records. Its singular directions identify strongly visible, weakly visible, and invisible combinations. A response-selected interface is one whose dominant response sector is persistent over the relevant interval, robust under small changes of background or coupling, and approximately closed against leakage into competing sectors.

This makes observability dynamical. A variable is not empirical merely because it appears in the global wavefunction. It becomes interface data when the cosmological evolution and record-forming interactions couple that variable, or some combination of variables, into a stable response channel.

Monotonicity: more records can only refine

If one interface algebra is enlarged by adding compatible records, its extension fiber can shrink but cannot grow. Any global state that agrees with the richer data automatically agrees with the poorer data. Thus additional observations may split an equivalence class that was previously unresolved, but they cannot merge states that were already distinguished.

This gives a clean meaning to experimental progress. A more capable interface need not reveal the entire global state. It does, however, reduce the family of global representatives compatible with what has been recorded.

The saturation criterion

Suppose a family of global proposals is labelled by a parameter $x$, while the realized observables depend on it only through a map $F(x)$. If $F$ is constant on a region $U$, then the interface is blind to how the proposals distribute their weight inside $U$.

Where every realized observable is saturated—constant across a range of global possibilities—differences within that range have no present empirical representative.

The proposals can still differ dramatically as global objects. But to distinguish them one must enlarge the interface with an observable whose induced map is nonconstant on that range. This is not a statement about ignorance or limited computing power. It is a statement about the information actually preserved by the physical restriction channel.

A worked cosmological sandbox: amplitude and phase

The Gaussian model in document 60 makes the abstract point concrete. For each cosmological perturbation mode, take an amplitude $\zeta_k$ and its conjugate momentum $p_k$. Linear evolution carries their initial values to a late record time. The stable late observable is generally a response-selected quadrature

$$Q_k^{\rm resp}=\zeta_k+\varepsilon_k p_k.$$

For super-Hubble modes, the growing solution approaches a constant while the decaying solution is suppressed. The response therefore becomes approximately rank one: $|\varepsilon_k|\ll1$. In the ideal strong-squeezing limit, $\varepsilon_k\to0$, the interface algebra is generated by functions of the amplitudes $\zeta_k$ alone.

Consider a Gaussian wavefunction

$$ \Psi_\Omega(\zeta)=N\exp\!\left[-\frac12\sum_k (\Omega_{R,k}+i\Omega_{I,k})\zeta_k^2\right]. $$

The exact amplitude algebra fixes the probability distribution $|\Psi(\zeta)|^2$, and therefore fixes $\Omega_{R,k}$. It does not fix the phase functional, represented here by $\Omega_{I,k}$. All changes of phase that leave the modulus unchanged lie in the extension fiber of the amplitude record.

At finite squeezing the distinction is graded rather than absolute. Since the actual record is $Q_k^{\rm resp}=\zeta_k+\varepsilon_kp_k$, its variance contains terms proportional to $\varepsilon_k\Omega_{I,k}$. Phase and decaying-mode data are therefore not categorically absent whenever $\varepsilon_k\neq0$; their influence is merely parametrically small and may fall below the realized resolution.

Why this matters The interface does not divide variables once and for all into “real” and “unreal.” It grades their empirical accessibility. Some directions dominate stable records, some survive weakly, and some vanish only in an asymptotic limit.

Presently invisible is not permanently meaningless

Because interfaces form and evolve, an extension direction can have several dynamical statuses:

  • not currently accessible: the present interface is blind, but a later admissible interface may record the difference;
  • partially retained: the interface distinguishes the states, but with less than the globally optimal discrimination power;
  • fully sufficient: the interface preserves enough information to recover the relevant proposal family;
  • dynamically stranded: no physically realized interface ever couples to the distinction;
  • representationally redundant: the difference disappears after gauge, phase convention, or other required quotienting.

This taxonomy prevents two opposite mistakes. Present inaccessibility should not automatically be turned into nonexistence. Conversely, a mathematical distinction in a chosen representation should not automatically be treated as physical.

Distinguishability and sufficiency

For a pair of candidate states, the trace distance measures their best possible single-measurement distinguishability. A physical interface is a quantum channel, and channels cannot increase trace distance. They can preserve the full distinction, retain only part of it, or erase it.

For an entire proposal family, the stronger notion is statistical sufficiency: there should exist a recovery channel that reconstructs every member of the family from the interface output, up to explicitly declared redundancies. Pairwise distinguishability is useful, but family-level recoverability is the more exact question.

This remains an audit performed after interface formation. Accessibility is not promoted to a substance, and no metaphysical transfer of “meaning” is assumed. The calculation asks only which differences the realized channel preserves.

Hartle–Hawking and tunnelling as a proposal audit

The Hartle–Hawking and tunnelling wavefunctions provide a natural application. They are global boundary proposals, not definitions of the interface ontology. To compare them empirically, both must be evolved through the same cosmological dynamics and the same physically derived record-forming channel.

Schematically, let $x$ label a semiclassical history and let $w_{\rm HH}(x)$ and $w_{\rm T}(x)$ be the proposal weights after conventions have been fixed. A realized observable map

$$x\longmapsto F(x)=(A_s,n_s,r,\Omega_k,\ldots)$$

pushes those weights forward to distributions over interface data. If $F$ is constant over a range on which the two proposals assign different weights, all observables generated by $F$ are blind to that redistribution. The difference survives empirically only in quantities whose maps remain nonconstant.

Earlier model calculations suggest a possible pattern: standard perturbation observables may saturate across broad inflationary ranges, while residual spatial curvature could retain sensitivity in a bounded window. This is an interesting target, not an established conclusion about the real universe. It depends on the chosen minisuperspace model, boundary prescriptions, measure, dynamics, and realized observational algebra.

A wider connection: reconstruction from partial algebras

The same formal shape appears in quantum gravity and holography. A boundary subalgebra can sometimes reconstruct only a corresponding bulk region; enlarging the boundary domain enlarges what can be reconstructed. Likewise, an interface algebra determines an equivalence class of global states, and additional compatible channels refine that class. The analogy is suggestive because both are inverse problems: infer global structure from restricted quantum data.

It would be an overclaim to identify an extension fiber with an entanglement wedge or to infer ER = EPR from the restriction formalism. The modest connection is that entanglement, algebraic access, and geometric reconstruction all ask which global distinctions are encoded in a specified subsystem. The interface framework supplies a precise language for that question even when no gravitational dual is assumed.

What the result does—and does not—settle

The framework gives a criterion for interface-relative equivalence and a calculable way to classify lost or suppressed directions. It does not select the correct cosmological boundary proposal, derive the actual late-time interface from first principles, or prove that every globally different state will eventually become observable somewhere.

Its central discipline is simpler:

A global difference matters to a specified empirical problem exactly to the extent that it survives in, perturbs, or can later be recovered from a physically realized interface.

That turns the vague question “Are these wavefunctions really different?” into a sequence of concrete ones: Which response channel forms? Which algebra does it generate? Which proposal parameters survive restriction? How much distinguishability is retained? Which residual differences are recoverable later, permanently stranded, or merely representational?
