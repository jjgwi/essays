Why Bounded Observers Need Interfaces

Home

Suppose two laboratories are built so far apart that neither can influence the other during an experiment. Every physicist would naturally expect each laboratory to have its own observations, its own measurements and its own records. We instinctively think of them as two independent systems.

Surprisingly, making this intuition precise is not as straightforward as it first appears. In modern quantum theory the world is not automatically divided into neatly separated pieces. Instead, the mathematical description begins as a single whole, while the familiar picture of independent laboratories has to emerge under suitable physical conditions.

This is where the idea of an interface enters these essays. An interface is not imagined as a physical membrane or a measuring device. Instead, it is the physical structure that allows part of the world to behave as an observable subsystem. It marks the transition from a global description to one that is meaningful for a bounded observer.

Different physical situations may realise such an interface in different ways. The important point is that the interface is not assumed at the beginning. First one asks which observable description is physically justified. Only then does one investigate how that description can be realised.

Seen from this perspective, the familiar idea of a laboratory is no longer taken for granted. It becomes something that physics itself should explain.
